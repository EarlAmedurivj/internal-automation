# internal-automation

Internal tooling for cloud infrastructure and developer workflows.

## What we build

- Log aggregation and summarization pipelines
- Configuration review and drift detection
- Documentation drafting for internal runbooks
- Automated incident triage notes

## LLM usage

We use large language models through cloud provider APIs (Amazon Bedrock)
to summarize logs, review configuration files, and draft internal
documentation. No end-user facing deployment; outputs are reviewed by
engineers before use.
